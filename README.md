# 长垣人寿 (2047) 官方网站前端工程

> **工程依据**：《长垣人寿官网_施工规范_v2.1》最高约束锁定标准构建。  
> **城市背景**：2047 年“仙都·长垣”。扎根长垣四十年，服务长垣人身保障与公共民生。  
> **产品定位**：真实人寿保险公司官网，融合“城市三层社保体系”、“合同期内锁价承诺”、“定点机构自动核验直赔”与“重大时刻真人负责”制度。严禁任何赛博朋克霓虹 HUD、加密货币、虚假无聊 AI 浮夸包装。

---

## 一、核心设计哲学与制度背景

1. **三层社会保障结构**：
   - **第一层**：不可耗尽的城市基本生命底线（公费托底，无终身封顶额度）。
   - **第二层**：公共动态个人与家庭互助共享池（跨代调剂，结余流转）。
   - **第三层**：雇主法定最低保障 + 长垣人寿商业补充保障（合同期内严格锁价）。
   - **硬性约束**：严禁把不同性质的风险保额粗暴相加为虚假单一总额。

2. **2047 未来感的真正体现**：
   - **极短流程**：终端一键加密互认，减少重复填表。
   - **自动核验**：定点公立医院与药房直赔，无需繁琐报销贴票。
   - **契约锁价**：承诺期内不因年龄增长或单次索赔任意涨价。
   - **透明解释**：穿透展示公共承担、长垣承担与个人自付比例。
   - **真人负责**：重大人生时刻（重特大伤病、争议申诉）由高级顾问（林秋、张文生）直接接管，绝不用机器人死循环推诿。

## 二、项目目录划分与维护规范

为方便**非程序员（运营、法务、产品）独立维护**，本项目严格践行“数据与文案分离”架构：

```
/
├── metadata.json                 # 应用元数据与平台声明
├── index.html                    # 网站 HTML 页面主入口 (同步 SEO 与标题)
├── ASSET_GUIDE.md                # 全站视觉资产与 AI 生图提示词维护指南
├── README.md                     # 本说明文档
├── src/
│   ├── app/                      # 全局状态 (AppContext.tsx)
│   ├── content/                  # 【纯文案与页面配置】非程序员维护区
│   │   ├── site.ts               # 品牌信息、Sitemap、页脚法定链接
│   │   ├── assets.ts             # 图片资产元数据、推荐比例与 AI 提示词
│   │   ├── pages/                # 7个 A 级核心页面的所有中文文案
│   │   │   ├── publicHome.ts     # 未连接终端首页文案
│   │   │   ├── personalHome.ts   # 已连接终端首页文案
│   │   │   ├── coverage.ts       # 我的保障页面文案
│   │   │   ├── plans.ts          # 保障方案页面文案与产品库
│   │   │   ├── policies.ts       # 我的保单页面文案
│   │   │   ├── claims.ts         # 理赔服务页面文案
│   │   │   └── support.ts        # 客户服务与常见 FAQ 文案
│   │   └── secondary/            # C 级普通二级页（公司、哲学、网点、条款等）
│   ├── data/                     # 【模拟业务数据】保单、理赔案卷、通知
│   ├── types/                    # TypeScript 类型定义（保障、合同、索赔等）
│   ├── components/               # 【纯视图组件】无硬编码文案
│   │   ├── layout/               # Header, Footer, PageShell
│   │   ├── common/               # AssetImage, 终端切换器, 模态框, 抽屉
│   │   └── insurance/            # 核心卡片 (PlanCard, PolicyCard, ClaimCard)
│   └── pages/                    # 页面容器（仅组织结构，从 content 注入数据）
```

### 如何修改网站文案？
1. 若需修改首页宣传语或公告：打开 `src/content/pages/publicHome.ts` 直接修改中文字符串。
2. 若需新增常见问题 FAQ：打开 `src/content/pages/support.ts` 中的 `faqs` 数组添加。
3. 若需修改保单锁价规则解释：打开 `src/content/pages/policies.ts` 修改。
4. **无需改动任何 TSX 页面代码**，即改即生效。

## 三、终端状态演练指南 (右下角切换器)

网站右下角内置了可折叠的 **“长垣终端状态演练台”**，用于完整体验 5 种业务场景：

1. **未连接终端 (UNCONNECTED)**：
   - 顶部导航仅展示公开菜单，右侧保留唯一“连接我的终端”入口。
   - 首页展示宽幅大图与品牌导览，无任何个人数据或隐私泄露。
2. **已连接终端 · 正常状态 (CONNECTED_NORMAL)**：
   - 首页自动变为个人工作台：陈墨涵身份、三层保障概览、待办事项（当前无待办）、直赔案件。
   - 顶部导航切换为已连接菜单，支持头像个人空间与通知中心。
3. **已连接终端 · 待处理事项 (CONNECTED_PENDING)**：
   - 首页高亮展示真实待办：保单续期确认、就诊补充说明。
   - 抽屉通知展示待办红点。
4. **已连接终端 · 争议复核中 (CONNECTED_DISPUTE)**：
   - 首页置顶案件争议横幅：`CLM-2047-002` 案件因自费特药剔除申请复核。
   - 同屏显示处理专员张文生及直接申诉通道。
5. **已连接终端 · 重大事件接管 (CONNECTED_MAJOR_EVENT)**：
   - 首页置顶危重绿色通道救治通知：高级专员林秋全程负责，先行垫付已启动，弱化任何商业推销。

## 四、全站页面清单

### 1. 7个 A 级核心页面（结构严格锁定）
- `/`：首页（根据终端连接状态自动呈现未连接或已连接首页）
- `/coverage`：**我的保障**（三层保障构成、重点风险评估、保障报告下载）
- `/plans`：**保障方案**（六大类方案库、自然语言生活场景咨询、产品卡片）
- `/policies`：**我的保单**（有效合同列表、锁价原因与承诺期限、变更指引）
- `/claims`：**理赔服务**（直赔机制、进行中案件、三层穿透结算单、补充报案）
- `/support`：**客户服务**（专属顾问林秋、终端数据授权、FAQ、线下营业厅）

### 2. B 级详情与流程页
- `/plans/:slug`：保障方案详情（涵盖保什么/不保什么、锁价规则、在线申请）
- `/policies/:id`：保单详情（保单凭证、条款全文、锁价承诺）
- `/claims/:id`：理赔详情（时间线、分担穿透结算单、争议复核）
- `/support/authorizations`：数据与授权管理（已授权系统、撤回授权）
- `/appeals`：投诉与申诉通道（48小时承诺、人工直通受理、无AI阻拦）

### 3. C 级普通与二级页面（拒绝空白页或 404）
- `/news` & `/news/:id`：新闻公告与法定信息公示
- `/sitemap`：全站完整结构地图
- `/about`：公司介绍与40年扎根长垣
- `/philosophy`：保障理念：从容与底线
- `/governance`：公司治理与合规公示
- `/disclosures`：偿付能力与公共定期披露
- `/careers`：人才招聘与成长
- `/branches`：线下网点全景
- `/agents`：专属服务顾问体系说明
- `/major-life-events`：重大人生事件保障指南
- `/claims-mechanism`：自动验证与直赔白皮书
- `/regulatory`：监管合规说明
- `/privacy`：隐私政策与数据最小必要声明
- `/terms`：网站使用条款
- `/contact`：联系我们与营业网点
